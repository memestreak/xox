# Export Kit: Implementation Plan

Spec: `docs/specs/2026-10-28-export-kit-design.md` (#179).
Branch: `issue-179-export-kit`. TDD: each task writes its
tests first, then the code, then runs the matching suite.

## App (TypeScript)

1. **`src/app/zipStore.ts`** — `crc32(bytes)` and
   `zipStore(entries: { name: string; data: Uint8Array }[])
   : Uint8Array`. Store method (0), UTF-8 names, fixed DOS
   date (1980-01-01) so output is deterministic, local
   headers + central directory + end record.
   Tests (`zipStore.test.ts`): CRC-32 of "123456789" is
   `0xCBF43926`; a tiny reader in the test walks the
   central directory and gets every name, size and byte
   back; empty entry; entry order kept.

2. **`src/app/kitExport.ts`** — pure helpers:
   - `slugify(name)`: lowercase, non `[a-z0-9]` runs to
     `-`, trim `-` (matches `build_kit.slugify`).
   - `KIT_ID_RE`, `isValidKitId(id)`.
   - `defaultExportName(kit)` = `${kit.name} custom`.
   - `KIT_SLOTS` = TRACK_IDS without `ac`.
   - `exportPlan(custom, disabled)`: per slot,
     `{ slot, file?: File }` (file only for custom slots
     that are on).
   - `buildKitZip({ kit, id, name, plan, fetchKitSample })`
     → `Promise<Uint8Array>`: reads custom `File` bytes,
     fetches the rest via `fetchKitSample(kit, slot)`
     (default: `fetch('/kits/<folder>/<slot>.wav')`,
     throwing on a non-OK response), writes `kit.json`
     (format 1, id, name, base, sources) first.
   Tests (`kitExport.test.ts`): slug cases, validity,
   plan with on/off/no custom, zip contents and kit.json,
   fetch failure rejects with the slot in the message.

3. **`src/app/ExportKitDialog.tsx`** — modal `<dialog>`
   following `SettingsModal` (showModal/close, `onClose`
   on the dialog's close event, `aria-labelledby`).
   Name and ID text inputs; ID follows `slugify(name)`
   until edited; invalid ID shows "Use lowercase letters,
   digits and single hyphens." and disables Export. Slot
   summary list. Export: `buildKitZip`, then download via
   `URL.createObjectURL` + a temporary `<a download>`;
   shows "Exporting..." while busy, the error inline on
   failure. Cancel button. Reads state via
   `useSequencer()`.
   Tests (`ExportKitDialog.test.tsx`): defaults from the
   current kit, ID follows name until edited, invalid ID
   disables Export, summary marks custom on/off, success
   calls the download with `<id>.zip` and closes, failure
   shows the error and stays open.

4. **`src/app/SettingsPopover.tsx`** — **Export kit...**
   item under Copy share link (download icon), opening
   the dialog (keyed like SettingsModal so it resets
   each open). Share link feedback becomes "Copied!
   Custom samples aren't included." when
   `state.customSamples` is non-empty.
   Tests: item opens the dialog; feedback text with and
   without custom samples.

5. **Docs** — CLAUDE.md: `zipStore.ts`, `kitExport.ts`,
   `ExportKitDialog.tsx`, the gear menu item, the dialog
   in the `keyboardUtils` list.

## Scripts (Python, load `python-development` skill)

6. **`assembler.trim_wav(path, slot)`** and `SLOT_CAPS` —
   16-bit PCM via `wave` + `array('h')`; threshold is
   peak × 10^(-50/20); keep 1 ms before the first frame
   over it; cut after the last; cap by slot; 20 ms linear
   fade (≤ ¼ of length); all-silent unchanged.
   `assemble_kit` calls it after `_convert` (not after
   `_write_silence`).
   Tests in `scripts/tests/test_kit_builder.py` on
   synthetic WAVs: lead trim with 1 ms pre-roll, tail
   trim, cap, fade ends at 0, silent untouched, stereo.

7. **`scripts/kit_builder/import_kit.py`** (executable):
   `read_export(zip_path) -> (meta, {slot: bytes})` with
   all step-1/2 checks raising `ImportError_` (a
   `ValueError` subclass) with a clear message;
   `import_kit(zip_path, replace=False)` doing convert →
   trim → verify in a temp dir under `KITS_DIR`, then
   install and update `kits.json` (replace keeps the
   entry's position); `main()` prints the report and the
   `git add` line, exits 1 with the message on error.
   Tests (`scripts/tests/test_import_kit.py`): each zip
   refusal, bad kit.json fields, clash / `--replace`,
   happy path with `_convert` patched to copy the WAV,
   nothing left behind on failure, verify catches a bad
   rate. `KITS_DIR`/`KITS_JSON` monkeypatched to tmp.

8. **README** in `scripts/kit_builder/` documents
   `import_kit.py` and the trim step.
